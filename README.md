# Sprint_6

Финальный проект шестого спринта курса «Инженер по тестированию» (Яндекс Практикум): UI-автотесты для учебного сервиса [«Яндекс Самокат»](https://qa-scooter.education-services.ru/) на Selenium с Page Object Model и Allure-отчётом.

## Стек

- Python 3
- pytest
- Selenium WebDriver (Mozilla Firefox)
- Allure (`allure-pytest`)

## Структура проекта

```
Sprint_6/
├── conftest.py          # фикстура driver: запуск Firefox и открытие главной страницы
├── pages/               # Page Object
│   ├── base_page.py     # BasePage — общие методы: клики, ввод, ожидания, работа с окнами
│   ├── faq_page.py      # FaqPage — раздел «Вопросы о важном»
│   └── order_page.py    # OrderPage — форма заказа и логотипы
├── scr/
│   ├── config.py        # URL сервиса
│   └── test_data.py     # тестовые данные для параметризации
├── tests/
│   ├── test_faq.py      # TestFAQ — выпадающий список «Вопросы о важном»
│   └── test_order.py    # TestOrder — заказ самоката и переходы по логотипам
└── allure_results/      # результаты прогона для Allure-отчёта
```

## Тесты

| Класс | Тест | Что проверяет |
|-------|------|---------------|
| `TestFAQ` | `test_faq_questions` | По клику на каждый из 8 вопросов открывается соответствующий ответ (параметризация по `FAQ_DATA`) |
| `TestOrder` | `test_create_order` | Позитивный сценарий заказа: два набора данных и две точки входа — кнопка «Заказать» вверху и внизу страницы (параметризация по `ORDER_DATA`) |
| `TestOrder` | `test_scooter_logo_redirect` | Клик по логотипу «Самоката» ведёт на главную страницу «Самоката» |
| `TestOrder` | `test_yandex_logo_redirect` | Клик по логотипу Яндекса открывает в новом окне главную страницу Дзена |

## Запуск

1. Установите Mozilla Firefox.
2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install pytest selenium allure-pytest webdriver-manager
   ```

3. Запустите тесты с сохранением результатов для Allure:

   ```bash
   pytest tests --alluredir=allure_results
   ```

4. Откройте отчёт (нужен установленный [Allure CLI](https://allurereport.org/docs/install/)):

   ```bash
   allure serve allure_results
   ```

## Задание

Нужно написать автотесты для учебного сервиса «Яндекс Самокат». Ручной тестировщик передал сценарии — их нужно покрыть автотестами, применив Page Object Model и подключив Allure-отчёт.

### 1. Подготовь проект

- Установи браузер Mozilla Firefox.
- Создай в IDE новый проект `Sprint_6`.
- Подключи Selenium и Allure.

### 2. Изучи тестовые сценарии

**Выпадающий список в разделе «Вопросы о важном».** Проверь, что по нажатию на стрелочку открывается соответствующий текст. На каждый вопрос нужен отдельный тест.

**Заказ самоката.** Проверь весь флоу позитивного сценария с двумя наборами данных. Точек входа в сценарий две: кнопка «Заказать» вверху страницы и внизу.

Позитивный сценарий:

1. Нажать кнопку «Заказать» (на странице их две).
2. Заполнить форму заказа.
3. Проверить, что появилось всплывающее окно с сообщением об успешном создании заказа.
4. Проверить, что по клику на логотип «Самоката» открывается главная страница «Самоката».
5. Проверить, что по клику на логотип Яндекса в новом окне через редирект открывается главная страница Дзена.

Тестов с разными данными — минимум два набора, данные на твоё усмотрение. Сценарий общий для обеих точек входа: не нужно дважды тестировать каждую из них.

### 3. Напиши тесты

- Опиши локаторы с помощью Page Object.
- Создай отдельный пакет для Page Object.
- Для каждой страницы создай отдельный класс Page Object.
- Напиши тесты на Selenium и раздели их по тематике или функциональности. Не нужно создавать отдельный класс для каждого теста — тесты на одну функциональность объединяй в один класс.
- Все тесты должны лежать в директории `tests`.
- Проверь, что тесты запускаются.
- **Обязательно используй параметризацию.** Где именно — реши самостоятельно.

### 4. Сделай отчёт в Allure

Сгенерируй Allure-отчёт и запушь его в репозиторий.
